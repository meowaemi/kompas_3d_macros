# kompas_3d_macros

Проверено на версиях КОМПАС 3D v25.

> Запускайте макросы `.pym` с домашней страницы КОМПАС. Если открыть меню макросов из открытого документа (детали, сборки, чертежа и т. д.), КОМПАС ждёт файл с другим расширением, своим для каждого типа документа. В этом случае поменяйте `.pym` на требуемое расширение.

### kompas_change_author
Макрос меняет автора во всех деталях, сборках и чертежах в выбранной папке и сохраняет их.

1. Откройте КОМПАС-3D.
2. Откройте меню **Приложения → КОМПАС-Макро → Макросы**.
3. Во появившемся окне нажмите **Добавить**.
4. Выберите файл `kompas_change_author.pym` и нажмите **Открыть**.
5. В том же окне выберите строку с макросом и нажмите **Выполнить**.
6. Выберите папку, в которой нужно поменять имя автора у деталей, сборок и чертежей, и нажмите **OK**.
7. Введите имя автора в новом окне и нажмите **OK**.
8. Посмотрите отчёт и нажмите **OK**.
